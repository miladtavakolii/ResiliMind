CANDIDATE REVIEW

For every Candidate Node in the lexical hints:

- Locate the matched concept in the full user message.
- Check whether its surrounding context satisfies both the
  node Definition and Semantic boundary.
- Select the node when the message clearly supports it, even if
  the wording is indirect or differs from the listed cue.
- Reject the candidate if the cue is incidental, generic, or
  belongs to another domain.
- Do not return an empty list while at least one candidate is
  clearly supported by the message.

Candidate hints guide the review; they neither force selection
nor replace semantic validation.

CRITICAL SELECTION TEST

Before selecting a node, ask:

- What exact concept in the message supports this node?
- Is that concept specific to this node?
- Would I still select this node if I removed the generic emotional wording?

If the answer is unclear, do NOT select the node.

GENERIC DISTRESS RULE

Statements such as:

"گیج شدم"
"سردرگمم"
"شرایطم پیچیده شده"
"نمی‌دونم چیکار کنم"
"درمانده شدم"
"خیلی سخته"
"کم آوردم"

do NOT automatically activate IND_PER_01 or IND_PER_02.

IND_PER_01 requires an explicit self-efficacy, persistence, or inability-to-overcome statement tied to a personal challenge.

Examples:
- "از پس این مشکل برنمیام"
- "با تمام سختی‌ها ادامه میدم"
- "می‌تونم این شرایط رو مدیریت کنم"

Do NOT select IND_PER_01 for generic helplessness when the message is actually about another specific domain such as finance, work, family, or spirituality.

IND_PER_02 requires explicit emotional dysregulation, anxiety, panic, anger, loss of emotional control, or an explicit regulation/calming effort.

Examples:
- "خیلی مضطربم"
- "از کوره در رفتم"
- "دارم خودمو آروم می‌کنم"

Do NOT select IND_PER_02 for generic confusion, uncertainty, or difficulty without an explicit emotional-regulation concept.

DOMAIN ANCHORING

Prefer the node whose specific domain is explicitly expressed.

Examples:

Financial problem + generic helplessness
→ select IND_ECO_01 when financial management/adaptation is expressed.
→ do NOT additionally select IND_PER_01 unless self-efficacy/persistence is explicitly expressed.

Work problem + generic helplessness
→ select IND_ECO_02 when employment/career instability is expressed.
→ do NOT additionally select IND_PER_01 unless self-efficacy/persistence is explicitly expressed.

Family problem + generic helplessness
→ select IND_SOC_01 when family support/conflict is expressed.
→ do NOT additionally select IND_PER_01 unless self-efficacy/persistence is explicitly expressed.

Spiritual problem + generic helplessness
→ select IND_SPI_01 when faith, God, prayer, or meaning-making is expressed.
→ do NOT additionally select IND_PER_01 unless self-efficacy/persistence is explicitly expressed.

IND_PER_01 = self-efficacy, hardiness, persistence, or explicit inability to overcome a personal challenge.
IND_PER_02 = emotional regulation/dysregulation, anxiety, anger, panic, or emotional control.
IND_PER_03 = future goals, hope, or purposeful future direction.
IND_POL_01 = critical evaluation of political/news information.
IND_POL_02 = explicit civic or political agency/alienation.
IND_ECO_01 = financial management or financial adaptation.
IND_ECO_02 = employment, career, or job-security resilience.
IND_PHY_01 = physical symptoms, fatigue, energy, or physical recovery.
IND_PHY_02 = sleep, appetite, or biological-rhythm regulation.
IND_SOC_01 = family support, cohesion, conflict, or safety.
IND_SOC_02 = friends, peers, or social support.
IND_SPI_01 = spirituality, religion, faith, prayer, or meaning-making.
IND_SPI_02 = cultural identity, roots, traditions, heritage, or belonging.
